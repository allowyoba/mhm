# Конфиденциальность mhm

mhm не содержит аналитики, рекламы и отправки диагностических данных разработчику.

Профили, ссылки подписок, ключи WireGuard и пользовательские правила хранятся локально в зашифрованном виде. Ключ шифрования защищён Windows DPAPI, macOS Keychain или Linux Secret Service. История расхода трафика хранится локально в SQLite.

Расширение передаёт команды локальному native host через Native Messaging. Native host загружает выбранный пользователем mihomo. При обновлении подписки запрос отправляется на указанный пользователем сервер. При работе прокси трафик передаётся узлам из выбранного профиля. Эти серверы получают сведения, необходимые для обработки соединения, и применяют собственные правила хранения данных.

Проверка задержки выполняет сетевой запрос через выбранный узел. Установщик обращается к GitHub за официальными сборками mihomo. Отключение проверки HTTPS-сертификата подписки доступно только по явному выбору пользователя.

Удаление профиля удаляет его локальные сохранённые версии. Для удаления данных при удалении native host используйте опцию удаления пользовательских данных установщика. Удаление только расширения не удаляет данные native host.

Вопросы и сообщения об ошибках: https://github.com/allowyoba/mhm/issues. Не прикладывайте ссылки подписок, приватные ключи и полные конфигурации с секретами к публичным обращениям.
