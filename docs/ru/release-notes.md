mhm 0.1.2 добавляет общие исключения IPv4/IPv6-подсетей. Они действуют во всех профилях, включая глобальный режим. Настройки проверяются перед сохранением и применяются переподключением активного профиля.

Закрытие последнего окна браузера и потеря native-канала завершают основной и временные WireGuard-процессы. Операции, ожидавшие сеть, не могут запустить новый core после завершения сеанса.

Для добавления профиля в Firefox отладка не требуется. Перед подключением mhm проверяет разрешение на работу в приватных окнах и объясняет, где его включить. Обновите native host вместе с расширением. Подписание и публикация новой версии в Mozilla Add-ons проходят отдельную проверку.

Пакеты Windows не подписаны Authenticode; сборки macOS не нотарифицированы. APT-архивы содержат локальные метаданные без публичной подписи. SHA256SUMS содержит контрольные суммы файлов релиза.
