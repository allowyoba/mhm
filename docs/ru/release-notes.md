Первый релиз mhm: профили и подписки mihomo, защищённое локальное хранение, обновление подписок через WireGuard, статистика и лимиты трафика, пользовательские правила и индикация подключения.

Расширения: Chrome, Edge, Firefox и Opera. Native host: Windows amd64, macOS arm64/amd64, Linux amd64/arm64. Для Linux доступны deb и архивы локального APT-репозитория.

Chrome, Edge и Opera: распакуйте ZIP и загрузите расширение в режиме разработчика. Firefox XPI из сборки не подписан, пока Mozilla не одобрит отправленную версию. В стабильном Firefox используйте подписанную версию из Mozilla Add-ons после её одобрения.

Windows установщик не имеет Authenticode-подписи; macOS сборки не нотарифицированы. Архивы APT содержат метаданные без публичной подписи и не являются размещённым APT-сервисом. Инструкция установки и ограничения находятся в README.

Файл SHA256SUMS содержит контрольные суммы всех приложенных пакетов. Исходный код привязан к тегу релиза.
